# Infinite Dungeon: Undergarden

A dimension addon for [Infinite Dungeon](https://github.com/HexaHexes/infinite-dungeon):
one new dungeon dimension with its own dungeon portal, themed and stocked from the
*Dungeon Crawl - Dimensional Patch* `dc_dp_undergarden` datapack (Curse project 1189484, file 6137053),
used as the content blueprint.

Scaffolded from [
eoforge-mod-template](https://github.com/HexaHexes/neoforge-mod-template).
Implementation is gated on the profile-driven core of the main repo: issues #162 and #163.
The plan lives in `docs/DEVELOPMENT_PLAN.md` there (sections 3, 16, 19, 20).

Sibling addons: infinite-dungeon-nether, -better-nether, -end, -better-end, -outer-end, -aether, -blue-skies, -undergarden.

Status: scaffold only - no gameplay content yet.
